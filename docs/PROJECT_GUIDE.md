# Proyecto SIICSA - Project Guide

## Overview
A web-based business management system built with JavaScript.

## Features
| Feature | Description |
|---------|-------------|
| Dashboard | Business metrics overview |
| Inventory | Product and stock management |
| Reports | Data visualization and exports |
| Users | Role-based access control |

## Setup
```bash
git clone https://github.com/NovaMan777/proyecto1_siicsa.git
cd proyecto1_siicsa
npm install
npm start
```

## Architecture
- Frontend: JavaScript + HTML/CSS
- Backend: Node.js/Express
- Database: MySQL/MongoDB
